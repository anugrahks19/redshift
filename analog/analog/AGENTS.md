# Workspace Frontend & Animation Rules

This workspace has specialized frontend, taste-skill (`design-taste-frontend`), scroll-craft, GSAP, and WebGL animation skills attached under `.agents/skills/`.

For **all frontend, landing page, UI motion, scroll-driven, or WebGL/3D tasks** in this workspace:

1. **Always consult the relevant `.agents/skills/*/SKILL.md` files before designing or writing frontend code:**
   - **Anti-slop frontend craft, layout, copy, typography, photography, and finish gate (`taste-skill`):**
     - `.agents/skills/design-taste-frontend/SKILL.md` (and its `references/`, `assets/`, `library/`, and `scripts/`)
   - **Scroll-driven sites & landing pages / layout craft / hero depth / visual verification:**
     - `.agents/skills/scroll-craft/SKILL.md` (and its `references/`, `engine/`, and `scripts/`)
   - **GSAP animations (timelines, ScrollTrigger, React `useGSAP`, plugins, utilities, performance):**
     - `.agents/skills/gsap-core/SKILL.md`
     - `.agents/skills/gsap-timeline/SKILL.md`
     - `.agents/skills/gsap-scrolltrigger/SKILL.md`
     - `.agents/skills/gsap-plugins/SKILL.md`
     - `.agents/skills/gsap-react/SKILL.md`
     - `.agents/skills/gsap-frameworks/SKILL.md`
     - `.agents/skills/gsap-utils/SKILL.md`
     - `.agents/skills/gsap-performance/SKILL.md`
   - **WebGL / Three.js / GLSL shaders / particle systems:**
     - `.agents/skills/threejs-animation/SKILL.md`
     - `.agents/skills/shader-glsl/SKILL.md`
     - `.agents/skills/particle-system/SKILL.md`

2. **Do not improvise generic templates or skip skill workflows** when a skill applies. Read the applicable `SKILL.md` and its referenced files first, then implement and verify according to its standards.
