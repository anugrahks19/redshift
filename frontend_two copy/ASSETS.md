# Image and effect sources

- Earth fallback: [NASA DSCOVR EPIC](https://epic.gsfc.nasa.gov/) natural-color full-disk photograph from July 15, 2024.
- Rotating Earth texture: [NASA SVS cloud-covered Blue Marble](https://svs.gsfc.nasa.gov/3615/) global satellite mosaic.
- Rotating Moon texture: [NASA SVS CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/) color map.
- Rotating Mars texture: [NASA/JPL Mars Image Texture](https://science.nasa.gov/3d-resources/mars/) planetary map.
- HalftoneReveal: Source supplied by the user from [React Bits](https://reactbits.dev/).
